Variation groups

New — on the recipe
Any name, any values. Required = every order must pick one. Optional = may be left empty; lines that need it are then skipped or fall back to their default. A group used by a line cannot be deleted.

Unchanged

Issue, Return, Close, variance, waste policy, stages, lot trace and the postings work as today. Complete gains one thing: several output lines, each into its own product (it already supports several outputs).

1 · Single product

Exists today

One product, one recipe, groups not asked. Every existing order and every recipe without groups.

Use when: one item, no colours or sizes (pharma, food, packaging).

2 · One variation

New

Same recipe, pick one value per group. One order = Red / M. Exact cost per variation.

Use when: the floor runs one colour/size at a time, or exact cost per size matters.

3 · Grid

New

Rows × columns of quantities on one order. One job card, cutting per colour, one Complete with many lines.

Use when: a buyer orders a size-colour mix (garments, footwear).

The two gaps that held 8.5 back are closed — the grid order (−1) and multi-group quantity (−0.5) — and both are now unlimited: any number of groups on a recipe line, any number of split-by groups on the grid. Remaining non-scored gap: piece-rate bundle tickets — a separate payroll feature.

Decisions still needed

Open
  • Grid after release: increase a cell = allowed; decrease below what is completed = refused; add a new cell = setting. Proposed.
  • Stages on a grid order: stage figures per output line, first stage worked per colour lay (shown in "On the floor"). Proposed.
  • Rule ties: two equally specific rules both match (e.g. M·Slim and M·Full for M/Slim/Full with no 3-group rule) → the upper row wins, and the recipe screen should flag the pair. Proposed: flag + upper row.
  • Output-line cap: company setting, default 300 lines per order. Proposed.
  • Modes per company: setting "Order modes" with three switches + a default; a mode switched off shows a disabled button with the reason.
  • Where a loss lands: shared by the whole order (shown — simple, one WIP pool) or kept inside its own line (needs WIP per line). Proposed: whole order.
  • Sale order grid → production grid: later phase.
